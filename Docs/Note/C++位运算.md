# C++ 位运算知识点

## 六大位运算符

只能用于整型操作数，直接操作二进制位，速度极快，常用来优化常数：

| 运算符 | 名称 | 规则 |
|--------|------|------|
| `&` | 按位与 | 同 1 为 1 |
| `\|` | 按位或 | 有 1 则 1 |
| `^` | 按位异或 | 不同为 1 |
| `~` | 按位取反 | 0↔1 |
| `<<` | 左移 | 低位补 0，等价 ×2ⁿ |
| `>>` | 右移 | 算术右移高位补符号位，等价整除 2ⁿ |

## 运算符优先级（最易踩坑）

位运算优先级整体很低，**混用算术/比较运算符必须加括号**。

优先级从高到低：算术（`* / %`、`+ -`）→ 移位（`<< >>`）→ 比较（`> < == !=`）→ `&` → `^` → `|` → 逻辑（`&& ||`）

两个典型坑：

```cpp
// 1. 加法优先级高于 &：n & 3 + 1 是 n & 4，不是 (n & 3) + 1
(n & 3 + 1) / 2    // 错：等于 (n & 4) / 2
((n & 3) + 1) / 2  // 对

// 2. 比较优先级高于 &：6 & 4 == 4 先算 4==4 得 1，再算 6 & 1
6 & 4 == 4         // 错：结果为 0
(6 & 4) == 4       // 对：结果为 1

// 3. 加减法优先级高于移位
1 << 3 + 7         // 错：等于 1 << 10
(1 << 3) + 7       // 对
```

## 常用技巧

### 单 bit 操作（掩码）

| 操作 | 写法 |
|------|------|
| 取第 k 位 | `(n >> k) & 1` |
| 第 k 位置 1 | `n \|= (1 << k)` |
| 第 k 位置 0 | `n &= ~(1 << k)` |
| 第 k 位取反 | `n ^= (1 << k)` |
| 取低 k 位 | `n & ((1 << k) - 1)` |

### 奇偶与幂判断

```cpp
(n & 1)                    // 1 为奇数
n > 0 && (n & (n - 1)) == 0  // 2 的幂（唯一的 1 被消除）
```

### 统计 1 的个数（Brian Kernighan）

```cpp
int cnt = 0;
while (n) { n &= n - 1; cnt++; }  // 每次消掉最右边一个 1，O(1 的个数)
```

### lowbit（树状数组核心）

```cpp
lowbit(x) = x & (-x);   // 取出最低位的 1 及后面的 0
// 例：n=10(1010)，lowbit = 2(10)
```

### 异或特性

- `a ^ a = 0`、`a ^ 0 = a` → 找丢失/重复的数字
- 无临时变量交换：`a ^= b; b ^= a; a ^= b;`（注意 a、b 不能是同一内存）
- 成对变换：`n ^ 1` 偶数→+1，奇数→-1（图论邻接表存无向边）

### 状态压缩（集合）

- 并集 `a | b`、交集 `a & b`、差集 `a & ~b`、对称差 `a ^ b`
- 枚举子集：

```cpp
for (int s = u; ; s = (s - 1) & u) {
    // 处理 s
    if (s == 0) break;
}
```

- 位图：`bitMap |= 1 << i` 添加；`(bitMap >> i) & 1` 检测（判断字符串字符是否唯一）

### 快速乘除 2 的幂

```cpp
x << k      // x * 2^k
x >> k      // x / 2^k（整除）
```

## 注意事项

1. **左移溢出**：`1 << i` 当 i 超过位数时溢出，用 `1ull << i` 或 `1LL << i`
2. **负数右移**：算术右移高位补 1（符号位），无符号数右移补 0
3. **优先级**：一切混合运算加括号，参考上文

## 典型应用场景

- 二进制状态压缩 DP（m 位 bool 数组压成一个整数）
- 树状数组（lowbit）
- 位图去重（字符唯一性）
- 快速幂：利用 `exp & 1`、`exp >>= 1` 加速
- 丢失/重复数字：异或
