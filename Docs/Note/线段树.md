# 线段树（Segment Tree）

## 简介

线段树是一种**二叉树**数据结构，用于高效处理**区间查询**和**点更新**问题。每个节点代表数组的一个区间，叶节点存单点，父节点存子区间的合并结果。

- 建树：O(n)
- 点更新：O(log n)
- 区间查询：O(log n)
- 空间：约 4n

## 适用场景

- 多次**修改 + 查询**交替的区间问题（静态数组用前缀和即可，无需线段树）
- 单点修改 + 区间求和/最值（LeetCode 307）
- 区间修改 + 区间查询（懒标记 lazy propagation）
- 复杂的区间合并信息（如 2213 最长重复字符段）

## 核心思想：节点信息的"合并"

线段树的难点在于**定义节点存什么、如何合并（merge）**。合并函数必须满足**结合律**，这样任意区间的信息都可以由子区间拼出来。

### 基础版：区间最大值 + 单点修改

```cpp
class SegTree {
    vector<int> tree;
    int n;

    void build(int o, int l, int r, vector<int>& a) {
        if (l == r) { tree[o] = a[l]; return; }
        int m = (l + r) / 2;
        build(o * 2, l, m, a);
        build(o * 2 + 1, m + 1, r, a);
        tree[o] = max(tree[o * 2], tree[o * 2 + 1]);
    }

    void update(int o, int l, int r, int idx, int val) {
        if (l == r) { tree[o] = val; return; }
        int m = (l + r) / 2;
        if (idx <= m) update(o * 2, l, m, idx, val);
        else update(o * 2 + 1, m + 1, r, idx, val);
        tree[o] = max(tree[o * 2], tree[o * 2 + 1]);
    }

    int query(int o, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[o];
        int m = (l + r) / 2, res = INT_MIN;
        if (ql <= m) res = max(res, query(o * 2, l, m, ql, qr));
        if (qr > m) res = max(res, query(o * 2 + 1, m + 1, r, ql, qr));
        return res;
    }
};
```

### 进阶版：复杂合并（LeetCode 2213 最长重复字符段）

节点存 5 个字段，合并时考虑**跨区间拼接**：

```cpp
struct Node {
    int pre;   // 前缀最长连续相同字符数
    int suf;   // 后缀最长连续相同字符数
    int best;  // 区间内最长重复字符段
    int len;   // 区间长度
    char first, last;  // 区间首尾字符
};

Node merge(Node a, Node b) {
    Node c;
    c.len = a.len + b.len;
    c.first = a.first;
    c.last = b.last;

    // 前缀：左子整体同字符且能连上右子，才延伸
    c.pre = a.pre;
    if (a.pre == a.len && a.last == b.first) c.pre += b.pre;

    // 后缀：对称
    c.suf = b.suf;
    if (b.suf == b.len && a.last == b.first) c.suf += a.suf;

    // 最优：左右子取大，再看跨边界拼接
    c.best = max(a.best, b.best);
    if (a.last == b.first) c.best = max(c.best, a.suf + b.pre);

    return c;
}
```

关键点：
- 每次更新只改一个叶子（pre=suf=best=1），沿路径向上重新 merge，O(log n)
- 全局答案 = 根节点的 `best`

## 懒标记（Lazy Propagation）

区间修改（如区间整体加 v）时，不做真正的下推，而是给节点打**懒标记**，查询/更新访问到该节点时才下传给子节点，摊还 O(log n)。

```cpp
struct Node {
    int sum;
    int lazy;  // 待下传的增量
};

void pushDown(int o, int l, int r) {
    if (tree[o].lazy == 0) return;
    int m = (l + r) / 2;
    // 下传给左右子
    tree[o*2].sum += tree[o].lazy * (m - l + 1);
    tree[o*2].lazy += tree[o].lazy;
    tree[o*2+1].sum += tree[o].lazy * (r - m);
    tree[o*2+1].lazy += tree[o].lazy;
    tree[o].lazy = 0;
}
```

## 常见优化与注意事项

1. **数组开 4n**：线段树最多约 4n 个节点，用 `vector<int> tree(4 * n)`
2. **下标从 1 开始**：`o*2`（左子）、`o*2+1`（右子），根为 1，避免 0 号节点下标冲突
3. **离散化**：值域太大时先离散化再建树（如 218）
4. **动态开点**：值域巨大但操作少时，不预分配 4n，用到哪个节点再 `new`（如 729 用 map 模拟）
5. 线段树解决的是**在线**多次操作问题；若所有查询已知且可离线，可考虑树状数组/离线算法
