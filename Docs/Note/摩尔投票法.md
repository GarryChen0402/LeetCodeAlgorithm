# 摩尔投票法（Boyer-Moore Majority Vote Algorithm）

## 简介

由 Robert S. Boyer 和 J Strother Moore 于 1981 年提出。用于在一组元素中寻找**多数元素**（出现次数超过 n/2 的元素），核心优势是 **O(n) 时间 + O(1) 空间**，也适用于数据流场景。

## 核心思想：对拼消耗

每次从序列中**选两个不同的元素删掉（抵消）**，最后剩下的就是出现次数超过一半的那个。

- 把众数记为 +1，其他数记为 -1，总和必然 > 0
- 不同阵营两两离场，多数阵营人数过半，最后必剩它的人

## 算法步骤

### 第一阶段：选定候选

1. `candidate = null`, `count = 0`
2. 遍历每个元素 `x`：
   - `count == 0` → 设 `candidate = x`, `count = 1`
   - `x == candidate` → `count++`
   - `x != candidate` → `count--`

### 第二阶段：验证

再次遍历统计 `candidate` 的实际出现次数，确认是否 > n/2。

> 若题目保证存在多数元素（如 LeetCode 169），可省略验证。

## C++ 实现

```cpp
int majorityElement(vector<int>& nums) {
    int candidate = 0, count = 0;
    for (int num : nums) {
        if (count == 0) candidate = num;
        count += (num == candidate) ? 1 : -1;
    }
    // 验证（题目保证存在多数时可省略）
    // int cnt = 0;
    // for (int num : nums)
    //     if (num == candidate) cnt++;
    // if (cnt > nums.size() / 2) return candidate;
    return candidate;
}
```

## 推广：超过 n/k 的情况

出现次数超过 n/k 的元素**最多只有 k-1 个**。

以 LeetCode 229（超过 n/3）为例，维护 **2 个候选 + 2 个计数器**：

- 元素属于 A 或 B → 对应计数器 +1
- 元素不属于 A、B，且两个计数器都 > 0 → 三者各 -1（三人抵消）
- 某计数器为 0 → 用当前元素替换
- 最后需要验证两个候选是否真的 > n/3

```cpp
vector<int> majorityElement(vector<int>& nums) {
    int a = 0, b = 0, ca = 0, cb = 0;
    for (int num : nums) {
        if (num == a) ca++;
        else if (num == b) cb++;
        else if (ca == 0) a = num, ca = 1;
        else if (cb == 0) b = num, cb = 1;
        else ca--, cb--;
    }
    // 验证阶段
    ca = cb = 0;
    for (int num : nums) {
        if (num == a) ca++;
        else if (num == b) cb++;
    }
    vector<int> res;
    if (ca > nums.size() / 3) res.push_back(a);
    if (cb > nums.size() / 3) res.push_back(b);
    return res;
}
```

## 注意事项

1. 若数组**不一定存在**多数元素，必须验证
2. 多数指**严格大于** n/2，等于 n/2 不算
3. 同样适用于流式数据（单次遍历、常数空间）
